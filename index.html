§03 — Projects

Things I've built

01Personal project · MLOps

Elvarsel

Next-day electricity-price forecasting for all 12 Nordic bidding zones, wrapped in a full MLOps lifecycle: ingestion, a point-in-time feature store, one LightGBM model for every zone with a calibrated 80% range, a read-only FastAPI service, a React dashboard and a scheduled daily retrain-and-forecast job.

In a 52-week walk-forward backtest it beats the naive "same hour yesterday" baseline in every zone, with 15–42% lower MAE.

02Personal project · ML

Busskoll

Live arrival predictions for Stockholm's SL buses. Every 90 seconds it reads SL's realtime feed, predicts when each bus reaches its next five stops with a LightGBM model that corrects SL's own forecast, and grades every prediction against the actual arrival and against SL.

In a 28-day walk-forward backtest against GPS-measured arrivals (lines 1, 4 and 6), its average error is 23% lower than SL's: 28.7 s against 37.3 s. The model runs in NumPy inside a FastAPI function on Vercel, with no database.
